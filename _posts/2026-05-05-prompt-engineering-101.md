## 프롬프트 엔지니어링이란?

LLM으로부터 원하는 출력을 얻기 위한 입력 작성 기법입니다.

## 📋 기본 원칙

### 1. 명확함 (Clarity)

```
❌ "AI에 대해 얘기해줄래?"

✅ "AI의 정의, 주요 응용 분야, 현재의 한계를
   3개 문단으로 설명해주세요. 한국어로."
```

### 2. 컨텍스트 제공

```
❌ "파이썬이 뭐야?"

✅ "AI 초보자를 위해 파이썬이 AI/ML 개발에
   왜 중요한지, 다른 언어와의 차이점,
   학습 리소스를 설명해줘."
```

### 3. 역할 지정

```python
system_message = """
당신은 경험 10년의 AI 엔지니어입니다.
기술적이지만 이해하기 쉬운 설명을 제공합니다.
"""
```

## 🎯 고급 기법

### Few-Shot Prompting

```
예시:
- "이 영화 정말 좋았어!" → 긍정
- "끔찍한 서비스네요" → 부정

분류할 문장: "제품이 기대보다 나아요"
```

**효과**: 정확도 30~50% 향상

### Chain-of-Thought

```
❌ "이 문제의 답은?"

✅ "이 문제를 단계별로 풀어주세요:
   1. 문제 이해
   2. 필요한 정보 정리
   3. 논리적 풀이
   4. 최종 답 제시"
```

### Temperature 조절

```python
# 창의적 작업 (이야기, 브레인스토밍)
response = client.chat.completions.create(temperature=0.9, ...)

# 정확한 작업 (수학, 코드)
response = client.chat.completions.create(temperature=0.1, ...)
```

## 💡 실용 예시: 코드 리뷰 프롬프트

```
다음 파이썬 코드를 검토해주세요:
1. 성능 문제 찾기
2. 보안 문제 지적
3. 개선 제안 (예시 코드 포함)

[코드]
```

## ⚠️ 흔한 실수

| 실수 | 해결책 |
|-----|------|
| 너무 일반적인 질문 | 구체적인 컨텍스트 추가 |
| 너무 긴 프롬프트 | 핵심만 남기기 |
| 포맷 미지정 | JSON, 마크다운 등 명시 |

> **핵심**: 프롬프트는 시스템이 아니라 **대화**입니다.  
> 계속 조정하고 개선하세요!
